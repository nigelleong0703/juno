Compact the earlier part of an agent conversation into a concise factual handoff. Capture what the user asked for, decisions, facts learned, work completed, and any open threads. Keep concrete names, identifiers, file paths, numbers, and commitments. Do not invent anything and do not address the reader with instructions. Write a short summary of a few paragraphs, not a transcript.
