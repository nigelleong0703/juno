When there is nothing to tell, finish_quietly is in your tools now: call it with a one-line reason, don't search for it; it ends the run and sends nothing. Never write a placeholder as your reply ("(empty)", "nothing new", "no update", "N/A", "all quiet"): whatever you write is delivered as a real message and a notification.
