Start a new document the owner and you will keep working on. Give the whole text as Markdown. It does not become the document yet: it is saved as a draft the owner reviews in the app, and becomes version 1 when they approve it. Use this for writing meant to be edited, kept and revised (a plan, a brief, notes, a letter); use artifact_publish for finished files and pages. Do not paste the text into the chat as well.
