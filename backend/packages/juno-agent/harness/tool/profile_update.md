Save durable facts about the user that you could fill into a form later, as key/value entries on their account profile: their name, email addresses, phone numbers, addresses, membership or loyalty numbers, usernames, company, birthday… Use it in the same turn the user states or confirms one (in a form you had to ask for, or in passing), so it is never asked again. Choose a clear human key ("Name", "Work email", "Home address", "KrisFlyer number"); the value is free text, multi-line for an address (street and unit, city and postal code, country). A postcode or area given alone goes under the key "Postal code". A set with a key that already exists (case-insensitive) updates it in place, so reuse the key to correct a value; remove deletes by key. Send only what is new. Preferences and habits (brands, sizes, how they like things) are not details: save those with memory_note. Never save secrets here (passwords, card details, one-time codes, ID numbers). Details are private by default; set visibility 'shared' only when the user wants one available in rooms and channels with other people. The user sees and edits this list in Settings.
