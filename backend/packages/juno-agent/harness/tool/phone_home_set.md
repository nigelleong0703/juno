Change one thing on one home accessory: turn it on or off, set a brightness, a target temperature or a position (blinds). Use the accessory's name from phone_home_list. Locks, garage doors, doors and alarms are never operated: the phone refuses, tell the user to do those themselves. The owner is asked first. Runs on the owner's iPhone through the Juno app, so it works only while the app is open (otherwise it is refused and says so).
