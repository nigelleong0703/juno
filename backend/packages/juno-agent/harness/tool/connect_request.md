Show the user a card with a button for each app in connectors (app ids such as gmail, google-calendar; find them with connector_search), or for the best catalog apps for a capability you name in need (mail.send, calendar.read…; label is then optional), in this chat: Connect for an app that is not added, Reconnect for one whose sign-in expired, never finished or lacks a permission, Turn on for one that is added but off for you.
