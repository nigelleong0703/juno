Where the owner's iPhone is right now: latitude, longitude, how far off that could be, and a place name when one is known. Approximate (a few kilometres) unless you ask for precise and the owner allowed precise location; the answer says which you got. One reading per call, nothing is tracked in the background. Do not repeat a location back to the user or anyone else unless it is needed for the task. Runs on the owner's iPhone through the Juno app, so it works only while the app is open (otherwise it is refused and says so).
