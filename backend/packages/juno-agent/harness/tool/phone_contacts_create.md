Add a new contact on the iPhone. Give a name or an organization, and any phone numbers and emails. Search first (phone_contacts_search): if the person is already there, use phone_contacts_add_detail instead of making a second card. The owner is asked first. Runs on the owner's iPhone through the Juno app, so it works only while the app is open (otherwise it is refused and says so).
