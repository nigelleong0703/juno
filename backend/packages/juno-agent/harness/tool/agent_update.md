Update an agent you own: its name, its one-line profile subtitle (description), or its persona. The persona is who the agent is and how it talks; it is the Persona field the owner sees under Identity (IDENTITY.md) and it replaces the whole text, so write the complete persona, not a change note. Change a persona only when the owner asked for it.
