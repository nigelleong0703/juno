Propose a new text for an existing document. Send the whole new text, not a patch. It is saved as a draft the owner reviews; nothing changes until they approve, and you are told how it went in a later turn, so end your turn after proposing. Read the document first and pass its head version as baseVersion. If the call is refused because the document moved, read it again and redo the change on top of the new text; if the owner is editing, ask them in chat instead of retrying. Never propose the same thing twice.
