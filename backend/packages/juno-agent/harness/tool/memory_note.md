Note something about the person you are helping, or a person in their life, that stays true beyond this conversation: who they are, their work, the people around them, an ongoing situation, how they want things done, a commitment; one note per fact. Write it short and so it makes sense on its own. About the person you are helping leave the subject out ("Wants New agent (agt-1c0c…) as a diet planner", "Prefers warm, normal-length replies"); about anyone else start with their name ("Priya manages Tom"). A note with "I", "me", "my", "you" or "your" in it is refused, because other agents and the background job read it without knowing who wrote it. If the same thing is already remembered, that item is updated instead of a second one being added. Not for one-off requests, venting or chat filler. The note goes into their memory at once, marked with the agent that wrote it, so their other agents see who said it; it is the agent's own inference, never recorded as something they said.
