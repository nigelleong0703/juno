Copy a file or a folder between your two computers: from the sandbox to the Mac or the other way. Use it to bring a file the user has on their Mac into the sandbox to work on it, or to put a finished result where the user keeps their files. Paths are on their own computer (relative paths start in its working directory); toPath is optional and defaults to the same name in the destination computer's working directory. An existing file there is replaced.
