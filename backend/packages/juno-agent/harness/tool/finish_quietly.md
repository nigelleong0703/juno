End this run without telling anyone anything: no message, no notification, no unread mark. Call it as your last action when you looked and there is nothing the person needs to hear: a routine or watch with nothing new, a check-in where nothing changed, a daily check that found no problem. `reason` is one short line for the person; the task list shows it as "Nothing to report: <reason>" (for example "No new AI news since yesterday's post"). Text you write in the same run is not sent. If there is something worth telling, do not call it: your final reply is delivered as a message. You have this tool only in work nobody is waiting on.
