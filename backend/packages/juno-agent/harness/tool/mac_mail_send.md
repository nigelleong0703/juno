Send an email from the Mail app. The owner is asked to approve every send, so write the full final message. Write only what this recipient may know: e.g. say you're away 6–9 Nov, not where or why; never include health, money or private plans unless the person you help asked you to share them. Works on the owner's Mac with the accounts set up in macOS Internet Accounts (Outlook, Exchange, iCloud, Google); needs Mac access for this agent.
