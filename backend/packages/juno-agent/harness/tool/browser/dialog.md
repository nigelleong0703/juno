Answer the native dialog (confirm, prompt, or leave-page) that blocks a tab of this agent's Chromium; tool results say when one is open and what it says. accept = OK, dismiss = Cancel; text fills a prompt. Alerts are accepted automatically. Before accepting a dialog that places an order, pays, commits money or deletes something, pass confirm (one sentence of what will happen); the user approves it first. The result includes a snapshot of the page afterwards.
